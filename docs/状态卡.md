## 两种模式（当前全部数值）

| 项 | 音游模式 | 经典模式 |
|---|---|---|
| 时长 | 整首歌 | 30 秒 |
| 背景音乐 | 从头播 | 播放中静音 |
| 音效 | 全部关闭 | 开 |
| 记分 | 基础 ×(1.0 / 0.62) + min(连击/10, 5) | 基础 1/3/5，连击每 3 个 +1（上限 +3） |
| 失误 | −4 分 + 断连 | −1 分 + 断连 |
| 最高分 | prefs `best` | prefs `bestC` |

- 判定：Perfect ±85 ms（×1.0，音高 1.0）；Good ±165 ms（×0.62，音高 0.84）
- 盆：银 1 拍 10 分 / 绿 2 拍 50 分 / 蓝 3 拍 30 分
- 谱面：3 轨 = 3 列，右→左滚动，提前 2600 ms 可见，播放头在 17%
- 音频默认：音效 20% / 音乐 50%（`volVer=2` 迁移）
- 背景音乐策略：**开始界面一直响**；音游模式 = 歌曲本体（不受开关影响）；结算静音；**经典对局看设置里的「音乐 开/关」**（默认关 = 保持原手感）
- 设置面板底部一排三个按钮：内置 / 震动 / 音乐（实心=开）

## 常用命令

```bash
python3 tools/release.py check                  # 本地 ↔ 远端差异（只读）
python3 tools/release.py push "说明"             # 只推有差异的文件，自动带删除
python3 tools/release.py push "说明" --ver 3.5   # 顺便升版本
python3 tools/release.py build                  # 等 CI 并取回 APK（约 80 秒）
python3 tools/release.py logs                   # 拉最近一次 CI 日志，只看报错行
python3 tools/release.py deploy /tmp/x.apk 名字  # 落到手机 Download
python3 tools/release.py all "说明" --ver 3.5 名字
```

只有 `WATCH` 范围（`app/ docs/ tools/ .github/` + 几个根文件）会被同步，`art/` 中间产物不会误传。

## 诊断通道（v3.4 起）

- 每局结束 App 把一段数字写进**系统剪贴板**，助手用 `/app/clip` 读走。
- 崩溃：写 prefs + 剪贴板；下次启动再把上次崩溃塞进剪贴板。
- 内容：版本/机型/分辨率、模式、bpm、拍数、谱面音符数、Perfect/Good/Miss、最大连击、判定误差均值与中位数 + 落在 ±85 ms 的比例、帧率 avg/min、音量与偏移、节拍缓存命中或分析耗时、最近 24 条事件。
- **为什么用剪贴板**：容器读不到 `/sdcard`（`/app/readfile` 被桥拒绝），剪贴板是唯一可用的「手机 → 助手」文字通道。日志文件另存 App 私有目录，将来有读法再用。
